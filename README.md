# MoitionCore
Servo tester
Motioncore™ is a servo tester but it can do more…

built my own servo tester – Motion Core
This is Motion Core, a servo tester I designed and built myself. But it’s a little different from a normal servo tester.
You can use it to test servos, position them by degrees, and even create animations — all completely standalone. No computer or software required.
I built it mainly as a tool for working on my animatronics projects, but it turned into a pretty useful little device on its own.

THIS IS ONLY A PROTOTYPE!
